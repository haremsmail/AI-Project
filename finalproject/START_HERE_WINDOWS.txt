🔴 PROBLEM YOU FACED:
  OSError: [Errno 2] No such file or directory
  Reason: Windows Long Path support is disabled (files longer than 260 characters)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ SOLUTION (3 STEPS - Takes 30 minutes total)

STEP 1: FIX WINDOWS (5 minutes + restart)
├─ Option A (Automatic):
│  └─ Run as Administrator: FIX_WINDOWS_PATHS.bat
│     Then: RESTART your computer ⭐ VERY IMPORTANT!
│
├─ Option B (Manual):
│  1. Press: Win + R
│  2. Type: regedit
│  3. Go to: HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\FileSystem
│  4. Find or create: LongPathsEnabled = 1
│  5. Close and RESTART your computer ⭐ VERY IMPORTANT!
│
└─ Check Success:
   After restart, you should be able to run:
   python -c "import sys; print(sys.maxunicode)"

STEP 2: INSTALL PROJECT (15 minutes)
├─ Option A (Fully Automated):
│  └─ Run: python setup_auto.py
│
├─ Option B (Batch File):
│  └─ Run as Admin: setup_simple.bat
│
└─ Option C (PowerShell):
   └─ Run as Admin: .\setup.ps1

STEP 3: RUN THE PROJECT (5 minutes)
├─ Activate environment:
│  └─ venv\Scripts\activate.bat
│     (You should see (venv) in your command line)
│
├─ Start Jupyter:
│  └─ python -m jupyter notebook
│     (Browser will open automatically)
│
└─ Open Notebook:
   1. In browser, find: notebooks/mango_leaf_disease_classification.ipynb
   2. Click it
   3. Click "Run All" button
   4. Wait 10-20 minutes for completion

❓ STILL NOT WORKING?

Problem: Setup fails immediately
└─ Solution: Run as Administrator (right-click file, Run as Admin)

Problem: Long path error still occurs
└─ Solution: 
   1. Restart computer completely (not just log off)
   2. Run setup again as Administrator

Problem: Jupyter not found
└─ Solution:
   1. Make sure (venv) shows in command line
   2. Try: pip install --upgrade jupyter ipykernel
   3. Then: python -m jupyter notebook

Problem: Python not recognized
└─ Solution: Reinstall Python from https://www.python.org/
   Make sure to check "Add Python to PATH" during install
